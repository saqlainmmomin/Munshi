# Munshi

Munshi is an early product concept for a renter-side apartment search agent in India. A search party describes what it needs once; Munshi continuously finds, ranks, qualifies, and coordinates promising rental properties while learning each participant's taste.

This repository currently preserves the product-discovery conversation that shaped the concept. No production implementation or final PRD has been created yet.

## Documents

- [Conversation record](docs/CONVERSATION.md) — chronological reconstruction of the product brainstorm, prototype decisions, and feasibility grill.

## Current product thesis

> Give us your requirements once. We continuously find and qualify flats until you have three worth visiting.

The initial pilot is a hybrid, concierge-assisted Bengaluru search agent. Durable data sources form the core; disclosed human-operated sourcing may be used during validation where automated access is restricted.
